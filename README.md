# Margin — 交易研究手记

一个面向美股与加密资产的个人研究空间。当前版本重点是可继续扩展的前端框架、阅读体验和本地记录。

## 启动

需要 Node.js 22.13+。已安装依赖的情况下：

```sh
npm run db:local
npm run dev
```

打开终端显示的本机地址，默认是 `http://127.0.0.1:5173/`。开发服务器仅绑定回环地址。

重新安装依赖时运行 `npm run install:ci`。数据库初始化命令可重复执行，已经执行的迁移不会重跑。

## 页面

- `/` 学习手记：按市场分类，新建、编辑，临时想法暂存。
- `/briefing` 市场札记：资讯列表框架和候选来源，尚未接入新闻采集。
- `/strategies` 策略研究：记录假设、入场、退出和风险约束；当前为可编辑草稿。
- `/reviews` 复盘：记录预期、实际结果和下一步。

所有栏目初始为空，不含演示行情、收益、新闻或交易记录。

## 保存位置

正式保存的记录在项目的 `.wrangler/state/v3/d1/` 本地数据库中，停止开发服务器后仍保留。浏览器 localStorage 仅用于未提交的编辑草稿及“随手记”。如果更换浏览器，已保存记录仍可从本机服务读取，但临时草稿不会随之转移。

本地数据库是用户数据，不要在清理构建缓存时删除 `.wrangler/state`。备份时先停止开发服务器，再复制整个 `.wrangler/state` 目录；恢复时放回相同位置。仓库忽略了这个目录，因此只备份源码不会备份记录。

## 代码入口

- `components/notebook.tsx`：页面布局、记录列表和编辑器。
- `app/globals.css`：颜色、字体、间距、桌面与移动布局。
- `lib/entries.ts`：记录类型和输入校验。
- `lib/entry-store.ts`：数据库读写，使用参数化 SQL。
- `app/api/entries/route.ts`：读取、新建、编辑接口；编辑冲突返回 409，避免旧内容覆盖新内容。
- `db/schema.ts` / `drizzle/`：数据库定义与迁移。
- `DESIGN-NOTES.md`：视觉方向与当前范围。
